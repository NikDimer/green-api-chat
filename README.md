# MAX Web — Чат через GREEN-API (React)

Пользовательский веб-интерфейс мессенджера MAX для отправки и получения сообщений с использованием сервиса **GREEN-API** по технологии **HTTP API**.

Разработано в рамках тестового задания на позицию «Фронтенд разработчик React».

---

## 🚀 Стек технологий

- **React 19** + **TypeScript**
- **Vite** — быстрая сборка и Hot Module Replacement (HMR)
- **Tailwind CSS v4** — современная адаптивная стилизация в эстетике [web.max.ru](https://web.max.ru/)
- **Lucide React** — иконки
- **GREEN-API**:
  - `SendMessage` — отправка текстовых сообщений
  - `ReceiveNotification` — получение входящих уведомлений из очереди FIFO
  - `DeleteNotification` — подтверждение получения и удаление уведомления из очереди

---

## 📋 Реализованный функционал

1. **Авторизация / Ввод учетных данных**:
   - Форма ввода `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.
   - Опциональная настройка API Host URL (по умолчанию `https://api.green-api.com`).
   - Сохранение учетных данных в `localStorage` (с возможностью выхода и смены аккаунта).
2. **Создание диалогов**:
   - Модальное окно создания нового чата с валидацией и нормализацией номера телефона получателя.
   - Автоматическое формирование идентификатора чата (`79991234567@c.us`).
3. **Отправка сообщений (SendMessage)**:
   - Отправка текстовых сообщений методом `POST {{apiUrl}}/waInstance{{idInstance}}/sendMessage/{{apiTokenInstance}}`.
   - Оптимистичное обновление интерфейса и индикация статуса отправки.
   - Отправка по клавише `Enter` (перенос строки по `Shift + Enter`).
4. **Получение сообщений по технологии HTTP API (FIFO Queue)**:
   - Фоновый процесс непрерывного опроса очереди методом `GET {{apiUrl}}/waInstance{{idInstance}}/receiveNotification/{{apiTokenInstance}}?receiveTimeout=5`.
   - При поступлении входящего сообщения (`incomingMessageReceived`) оно автоматически отображается в соответствующем чате.
   - Сразу после обработки вызывается `DELETE {{apiUrl}}/waInstance{{idInstance}}/deleteNotification/{{apiTokenInstance}}/{{receiptId}}` для очистки очереди.
5. **Интерактивная панель логов очереди**:
   - Встроенный монитор очереди HTTP API в реальном времени (кнопка с иконкой антенны в шапке сайдбара).
   - Отображает вызовы `ReceiveNotification`, `DeleteNotification`, receiptId и полезную нагрузку.
6. **Интерфейс в стиле MAX Web**:
   - Сайдбар со списком чатов, поиском, аватарами и временем последнего сообщения.
   - Область диалога с «пузырями» сообщений, временем и отметками доставки.
   - Адаптивный дизайн.

## 🛠️ Инструкция по локальному запуску

### 1. Предварительные требования
- Установленный **Node.js** (версии 18.x или новее)
- Менеджер пакетов **npm** (или pnpm / yarn)

### 2. Установка и запуск

1. Перейдите в директорию проекта:
   ```bash
   cd green-api-chat
   ```

2. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте в браузере адрес, указанный в терминале:
   ```
   http://localhost:5173
   ```

### 3. Сборка для продакшена (Production Build)

```bash
npm run build
```
Статические файлы будут скомпилированы в папку `dist/`. Для локального предпросмотра собранной версии выполните:
```bash
npm run preview
```

## 📖 Как протестировать работу приложения

1. Откройте приложение в браузере.
2. В появившемся окне авторизации введите ваш `idInstance` и `apiTokenInstance` из кабинета [console.green-api.com](https://console.green-api.com).
3. Нажмите кнопку **«+»** (Новый диалог) в левой панели и введите номер телефона получателя (например, `79991234567`).
4. Напишите текстовое сообщение и нажмите кнопку отправить (или клавишу `Enter`).
5. Когда получатель ответит в мессенджере MAX, входящее сообщение поступит в очередь GREEN-API, будет получено методом `ReceiveNotification`, удалено методом `DeleteNotification` и появится в окне диалога.
6. Для наглядности откройте монитор очереди по кнопке антенны в шапке сайдбара — там в реальном времени отображаются все вызовы HTTP API.
